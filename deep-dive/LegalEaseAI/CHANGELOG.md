# Changelog

All notable changes to LegalEase AI will be documented in this file.

## [1.0.0] - 2026-04-18

### Added
- Enterprise-grade repository structure and documentation.
- One-click launch script (`launch.ps1`) for Windows environments.
- CI/CD workflow for automated builds and testing.
- Documentation for System Architecture and Contributing.
- Context-aware AI Assistant that recognizes document analysis results.
- Multi-user data isolation (each user only sees their own chats, cases, and documents).
- Persistent local mock database fallback (`server/mockData.json`) for seamless offline development.
- Fully interactive Dashboard and Case Management UI.

### Fixed
- Resolved all dead navigation links and non-interactive buttons.
- Fixed chat thread switching and new conversation initialization.
- Corrected document analysis suggestions hand-off logic.
